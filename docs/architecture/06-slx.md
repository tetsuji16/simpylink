## 3. 方針（確定）

1. **元ファイルを上書きしない**。SLX を開いたモデルの「保存」は既定で JSON（`<name>.simpylink.json`）。SLX 書き出しは「Export as SLX…」で別名を必須とし、既存ファイル選択時は確認ダイアログ。
2. **未対応要素は保持**：L2 の XmlNode 木と未解釈パートのバイト列を `PreservedData` に保持し、書き出し時に再出力する。
3. **データ損失の警告**：インポート時に `ImportReport { unsupported_blocks, unsupported_params, dropped: Vec<String>, warnings }` を作り GUI に一覧表示。「Preserved（往復で保持）」「Dropped（失われる）」を区別。
4. **互換判定の段階**：(a) 構造解析成功 (b) simpylink 上で同じ数値結果 (c) 書き出したファイルを R2026b が警告なく開ける (d) R2026b でのシミュレーション結果一致。**(c)(d) を満たすまで「双方向互換」と表記しない。**
5. MDL（テキスト形式）は M6 以降の別 Issue。
