# [DES-04] 設計契約：生成 Python コード形式・Runner プロトコル・結果ファイル

> **設計契約**。生成コードは `generator format 1`。この形式を変える場合は format 番号を上げ、この Issue を更新する。

## 1. 生成コードの原則
1. 依存は Python 標準ライブラリ + NumPy + SciPy のみ。simpylink の Python パッケージは存在しない。
2. GUI なしで `python <file>.py --out-dir <dir>` で実行できる。
3. ファイルは **2部構成**：(a) モデル固有部（設定・パラメータ・状態・`compute_outputs` 等）、(b) **固定ランタイム**（全モデルで1文字も変わらない `simulate()` / `main()` 等）。
4. 決定的：同じ IR から同じバイト列。タイムスタンプを埋め込まない。改行は `\n`、末尾改行1つ、インデントは空白4、行末空白なし。
5. 浮動小数点リテラル：Rust の `format!("{:?}", v)`（例 `3.0`, `0.001`, `1e-6`）。`+∞` → `math.inf`、`−∞` → `-math.inf`。NaN は IR 段階で禁止。

## 2. ファイル構成（この順序で出力する）

| 節 | 内容 |
|---|---|
| ヘッダ | shebang、docstring（Model 名、Generator 版）、import |
| `MODEL_NAME` | `MODEL_NAME = "<model_name>"`（JSON 文字列エスケープ） |
| Simulation settings | START_TIME, STOP_TIME, OUTPUT_STEP, SOLVER, REL_TOL, ABS_TOL, MAX_STEP, FIXED_STEP（可変ステップは `None`、固定ステップは具体値） |
| Block parameters | 実行順ではなく **sid 昇順** に `# <name> (SID n)` + 定数。パラメータの無いブロックは出力しない |
| States, rates and logging | NUM_CONT_STATES, X0, NUM_DISC_STATES, D0, DISCRETE_RATES, BREAKPOINTS, LOG_CHANNELS |
| `compute_outputs(t, x, d, t_seg)` | 実行順に `# <name> (SID n)` + 代入文。出力の無いブロック（Scope, Outport）は出力しない。最後に全信号の dict を返す（キーは実行順） |
| `compute_derivatives(t, x, d, t_seg)` | 連続状態ブロックごとに `dx[i] = ...`（sid 昇順） |
| `update_discrete_states(t, x, d, y, hits)` | 離散ブロックごとに `if <rate> in hits:` ブロック（sid 昇順） |
| `log_values(y)` | LOG_CHANNELS 順にリスト |
| 固定ランタイム | 下記 §4 の全文 |

## 3. 正解例：Step → Gain → Scope（ゴールデン、`tests/fixtures/expected/step_gain_scope.py`）

入力モデル：#18 §3.1 の JSON。下記は **一字一句このとおり** に生成されること（Issue #60 のゴールデンテスト）。

```python
#!/usr/bin/env python3
"""Simulation code generated by simpylink.

Model: step_gain_scope
Generator: simpylink-codegen-py 0.1.0 (format 1)

Standalone: requires only Python >= 3.10, NumPy and SciPy.
Run: python step_gain_scope.py --out-dir results
"""

import argparse
import json
import math
import os
import sys
import traceback

import numpy as np
from scipy.integrate import solve_ivp

MODEL_NAME = "step_gain_scope"

# ---------------------------------------------------------------------------
# Simulation settings
# ---------------------------------------------------------------------------
START_TIME = 0.0
STOP_TIME = 2.0
OUTPUT_STEP = 0.5
SOLVER = "RK45"
REL_TOL = 0.001
ABS_TOL = 1e-6
MAX_STEP = math.inf
FIXED_STEP = None

# ---------------------------------------------------------------------------
# Block parameters
# ---------------------------------------------------------------------------
# Step (SID 1)
STEP_1_TIME = 1.0
STEP_1_BEFORE = 0.0
STEP_1_AFTER = 2.0
# Gain (SID 2)
GAIN_2_GAIN = 3.0

# ---------------------------------------------------------------------------
# States, rates and logging
# ---------------------------------------------------------------------------
NUM_CONT_STATES = 0
X0 = []
NUM_DISC_STATES = 0
D0 = []
DISCRETE_RATES = []
BREAKPOINTS = [1.0]
LOG_CHANNELS = [
    {"name": "Scope/1", "block_sid": 3, "port": 1},
]


def compute_outputs(t, x, d, t_seg):
    """Compute every block output at time t in execution order."""
    # Step (SID 1)
    step_1 = STEP_1_AFTER if t_seg >= STEP_1_TIME else STEP_1_BEFORE
    # Gain (SID 2)
    gain_2 = GAIN_2_GAIN * step_1
    return {
        "step_1": step_1,
        "gain_2": gain_2,
    }


def compute_derivatives(t, x, d, t_seg):
    """Return dx/dt for the continuous states."""
    y = compute_outputs(t, x, d, t_seg)
    dx = np.zeros(NUM_CONT_STATES)
    return dx


def update_discrete_states(t, x, d, y, hits):
    """Return the discrete state vector after the sample hits in `hits`."""
    d_next = d.copy()
    return d_next


def log_values(y):
    """Return the logged values in LOG_CHANNELS order."""
    return [
        y["gain_2"],
    ]


# ===========================================================================
# Fixed runtime (identical in every generated file; generator format 1)
# ===========================================================================
class SimulationError(Exception):
    """Raised when the simulation cannot continue."""


def _time_tolerance():
    return 1e-9 * max(1.0, abs(START_TIME), abs(STOP_TIME))


def major_time_points():
    """Return a sorted list of (t, is_output, hit_rate_indices)."""
    tol = _time_tolerance()
    events = []
    k = 0
    while True:
        t = round(START_TIME + k * OUTPUT_STEP, 12)
        if t > STOP_TIME + tol:
            break
        events.append((t, "output", None))
        k += 1
    events.append((STOP_TIME, "output", None))
    for t in BREAKPOINTS:
        if START_TIME - tol <= t <= STOP_TIME + tol:
            events.append((t, "break", None))
    for index, (period, offset) in enumerate(DISCRETE_RATES):
        k = 0
        while True:
            t = round(offset + k * period, 12)
            if t > STOP_TIME + tol:
                break
            if t >= START_TIME - tol:
                events.append((t, "hit", index))
            k += 1
    events.sort(key=lambda e: e[0])
    points = []
    for t, kind, index in events:
        if points and abs(t - points[-1][0]) <= tol:
            t0, is_output, hits = points[-1]
        else:
            t0, is_output, hits = t, False, ()
            points.append((t0, is_output, hits))
        if kind == "output":
            is_output = True
        if kind == "hit" and index not in hits:
            hits = hits + (index,)
        points[-1] = (t0, is_output, hits)
    return points


def simulate():
    """Run the simulation and return (times, values) as NumPy arrays."""
    x = np.array(X0, dtype=float)
    d = np.array(D0, dtype=float)
    times = []
    rows = []
    points = major_time_points()
    for i, (t, is_output, hits) in enumerate(points):
        y = compute_outputs(t, x, d, t)
        if is_output:
            times.append(t)
            rows.append(log_values(y))
        if hits:
            d = update_discrete_states(t, x, d, y, hits)
        if i + 1 < len(points) and NUM_CONT_STATES > 0:
            t_next = points[i + 1][0]
            d_hold = d
            sol = solve_ivp(
                lambda tt, xx: compute_derivatives(tt, xx, d_hold, t),
                (t, t_next),
                x,
                method=SOLVER,
                rtol=REL_TOL,
                atol=ABS_TOL,
                max_step=MAX_STEP,
            )
            if not sol.success:
                raise SimulationError(
                    f"solver failed between t={t!r} and t={t_next!r}: {sol.message}"
                )
            x = sol.y[:, -1].copy()
    return np.array(times, dtype=float), np.array(rows, dtype=float).reshape(len(times), len(LOG_CHANNELS))


def _format_number(value):
    return repr(float(value))


def write_results(out_dir, times, values, status="ok", error=None):
    """Write results.csv and results.meta.json into out_dir."""
    os.makedirs(out_dir, exist_ok=True)
    csv_path = os.path.join(out_dir, "results.csv")
    with open(csv_path, "w", encoding="utf-8", newline="\n") as f:
        f.write(",".join(["time"] + [c["name"] for c in LOG_CHANNELS]) + "\n")
        for t, row in zip(times, values):
            f.write(",".join(_format_number(v) for v in [t, *row]) + "\n")
    meta = {
        "format": "simpylink-results",
        "format_version": 1,
        "model": MODEL_NAME,
        "status": status,
        "error": error,
        "num_samples": len(times),
        "channels": LOG_CHANNELS,
    }
    with open(os.path.join(out_dir, "results.meta.json"), "w", encoding="utf-8", newline="\n") as f:
        json.dump(meta, f, indent=2)
        f.write("\n")


def main(argv=None):
    parser = argparse.ArgumentParser(description=f"Simulate model {MODEL_NAME!r}.")
    parser.add_argument("--out-dir", default="results", help="directory for results.csv")
    args = parser.parse_args(argv)
    print("SIMPYLINK:START", flush=True)
    try:
        times, values = simulate()
    except Exception as exc:  # report every failure to the caller
        write_results(args.out_dir, [], [], status="error", error=f"{type(exc).__name__}: {exc}")
        print(f"SIMPYLINK:ERROR {type(exc).__name__}: {exc}", file=sys.stderr, flush=True)
        traceback.print_exc()
        return 1
    write_results(args.out_dir, times, values)
    print(f"SIMPYLINK:DONE samples={len(times)}", flush=True)
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

## 4. 固定ランタイム

上記ファイルの `# Fixed runtime (identical in every generated file; generator format 1)` 見出し（直前の空行2行を含む）から末尾までが固定ランタイム。sim_codegen_py はこれを `include_str!("runtime_format1.py")` で埋め込み、**改変せず** 連結する。

固定ステップ（DES-07 §2.3、#159）：`FIXED_STEP` が `None` でなければ `major_time_points()` が `START_TIME + k*FIXED_STEP` を `"step"` 種別で加え（`is_output` は立てない）、`simulate()` は `solve_ivp` の代わりに `fixed_step(fun, t, h, x, method)`（Butcher 表 `_TABLEAUS` による 1 段）で区間を進める。`SOLVER == "discrete"` は積分しない。可変ステップのモデルは `FIXED_STEP = None` の 1 行以外は従来と同一。

## 5. 結果ファイル（Python → Rust）

出力ディレクトリ `<out-dir>/` に2ファイル。

### 5.1 `results.csv`
- UTF-8、改行 `\n`、区切り `,`、引用符なし。
- 1行目ヘッダ：`time` + LOG_CHANNELS の name。
- 数値は Python `repr(float(v))`：`6.0`, `0.30000000000000004`, `nan`, `inf`, `-inf`。
- 行数 = 1 + num_samples。

### 5.2 `results.meta.json`
```json
{
  "format": "simpylink-results",
  "format_version": 1,
  "model": "step_gain_scope",
  "status": "ok",
  "error": null,
  "num_samples": 5,
  "channels": [
    {
      "name": "Scope/1",
      "block_sid": 3,
      "port": 1
    }
  ]
}
```
失敗時：`"status": "error"`、`"error": "SimulationError: solver failed ..."`、`num_samples: 0`、CSV はヘッダ行のみ。

## 6. Runner プロトコル（Rust → Python 子プロセス）

| 項目 | 契約 |
|---|---|
| コマンド | `<python> [prefix_args...] -u <script.py> --out-dir <out_dir>`（`-u` で標準出力をバッファしない） |
| 作業ディレクトリ | `<out_dir>` |
| 環境変数 | `PYTHONIOENCODING=utf-8` を追加。他は継承 |
| stdout | `SIMPYLINK:START`、成功時 `SIMPYLINK:DONE samples=<n>`。その他の行はユーザー出力として GUI に表示 |
| stderr | 失敗時 `SIMPYLINK:ERROR <ExcType>: <msg>` + Python traceback |
| 終了コード | 0 成功、1 シミュレーション失敗、2 引数エラー（argparse）、その他 = 異常終了 |
| 停止 | Rust 側から `Child::kill()`。停止後は結果ファイルを読まない（status = Stopped） |
| 成功判定 | 終了コード 0 **かつ** `results.meta.json` の status == "ok" **かつ** CSV 行数 == 1+num_samples |

### 6.1 Python の探索順（`discover_python`）
1. `RunnerConfig.python` が Some → そのパス
2. 環境変数 `SIMPYLINK_PYTHON`
3. Windows：`py -3`（program=`py`, prefix_args=[`-3`]）→ `python` → `python3`
4. Linux/macOS：`python3` → `python`
各候補で `<cand> -c "import sys; print('%d.%d.%d' % sys.version_info[:3])"` を実行し、3.10 以上の最初の候補を採用。

### 6.2 環境確認（`check_environment`）
`<python> -c "import numpy, scipy; print(numpy.__version__); print(scipy.__version__)"` を実行し、`EnvReport { python_version, numpy_version: Option<String>, scipy_version: Option<String> }` を返す。import 失敗時は `RunnerError::MissingPackage { name, hint: "python -m pip install numpy scipy" }`。

## 7. Rust 側型（`sim_runner`、確定）
```rust
#[derive(Debug, Clone, PartialEq)]
pub enum RunEvent { Started, Stdout(String), Stderr(String), Finished(RunOutcome) }
#[derive(Debug, Clone, PartialEq)]
pub enum RunStatus { Succeeded, Failed { exit_code: Option<i32>, message: String }, Stopped, TimedOut }
#[derive(Debug, Clone, PartialEq)]
pub struct RunOutcome { pub status: RunStatus, pub stdout: Vec<String>, pub stderr: Vec<String>, pub elapsed: std::time::Duration }
#[derive(Debug, Clone, PartialEq)]
pub struct Channel { pub name: String, pub block_sid: u32, pub port: u32, pub values: Vec<f64> }
#[derive(Debug, Clone, PartialEq)]
pub struct SimResults { pub model: String, pub time: Vec<f64>, pub channels: Vec<Channel> }
#[derive(Debug, thiserror::Error)]
pub enum RunnerError {
    #[error("Python 3.10+ was not found (tried: {tried:?}). Set SIMPYLINK_PYTHON or choose Python in Settings.")] PythonNotFound { tried: Vec<String> },
    #[error("Python package '{name}' is missing. Install with: {hint}")] MissingPackage { name: String, hint: String },
    #[error("failed to start Python: {0}")] Spawn(String),
    #[error("I/O error: {0}")] Io(#[from] std::io::Error),
}
#[derive(Debug, thiserror::Error)]
pub enum ResultsError {
    #[error("results file missing: {0}")] Missing(String),
    #[error("invalid results.meta.json: {0}")] Meta(String),
    #[error("invalid results.csv at line {line}: {message}")] Csv { line: usize, message: String },
    #[error("simulation reported error: {0}")] Reported(String),
}
```
